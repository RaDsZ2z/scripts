# Scripts

日常使用的脚本和小型工具集合。

## 工具

- `replace.py`：批量替换字符串。
- `pillow.py`：翻转图片。
- [`proto_simulator/`](proto_simulator/)：游戏协议模拟器，可通过命令行交互式发送和接收协议，无需启动客户端。
- [`AI生图/`](AI生图/)：Banana AI 生图工作台，支持浏览器操作、批量任务、参考图以及 JSON/Excel 导入。

## AI 生图工作台

本地使用时双击 `AI生图/start.bat`。详细的启动方法、工作区和导入格式见 [`AI生图/app/README.md`](AI生图/app/README.md)。
